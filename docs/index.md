## 评论区找人打招呼

社交媒体提供与未关注你的用户互动的四种途径：

1. 发作品
2. 在作品下方评论
3. 在评论下方回复
4. 从用户主页进入私信界面，打招呼

第四种途径限制严格，比如在小红书上，每天只能给十个未关注你的用户打招呼，且打招呼时只能发一条消息，而前三种途径几乎是不限量的（发多了平台会不会限流就两说了）。

但是，如果需要私信进行后续互动，而不是一直公开互动，那么，第四种途径会更好。

社交媒体对诱导转到私信进行互动这一行为的打击力度非常大，但凡说了几次“回关一下”“私我”，被平台检测到了，你的帐号功能就会受到限制。

通过第四种途径，只要对方响应你的招呼，平台就允许你继续给对方发私信了，不要求一定要对方关注你。

换句话说，别人公开响应你与你互动，平台并不会自动允许你私信向对方发送多条消息，而别人私信响应你与你互动，平台就会允许你畅聊。

所以，直接以私信开始互动，比较适合需要私信进行后续互动的场合。

要注意，每天只有为数不多的打招呼机会，假如每天只有十次打招呼机会，倘若你打招呼的响应率低于十分之一，那么每天响应你的预计人数就会低于一。

最好将打招呼机会，尽可能用在表达强烈私信互动欲望的用户身上，比如在相关作品下方评论有需要的用户。

我称之为“评论区找人打招呼”。

线上社交是一个非常契合它的应用场景，刷到隐隐感觉志同道合的评论，就大胆向对方发私信吧，说不定成了一段佳话的开端。

每天为数不多的打招呼机会，与其说是限制，不如说是在倒逼你，把宝贵的热情投入到更有可能产生共鸣的关系中。
