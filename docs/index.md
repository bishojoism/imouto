# 处兄妹攻略

## 指标

1. 用户获取：热门作品评论要哥哥的女生（每周固定40个）
2. 用户激活：响应招呼愿意当妹妹的女生（每周大约10个）
3. 用户存留：联系三天换来回消息的女生（每周大约4个）
4. 用户收益：相处期间始终守纪律的女生（每周大约1个）
5. 用户推荐：没有也不需要

## 流程

1. （一次性）准备微信，昵称头像简介填低龄化的，性别年龄地区填真的，可白板号可老号，但最好将朋友圈设为三个月可见。
2. （一次性）准备小红书，昵称头像简介填低龄化的，性别年龄地区填真的，可白板号可老号，但最好将你关注了谁、谁关注了你设为仅自己可见。
3. （每批5分钟，每天2批，每周4天）小红书搜“收妹妹处兄妹”作品，对于评论区里新留言要哥哥的女生：关注并私信“我想收一些妹妹，你能当我妹妹吗”，直到用完小红书每天的10次招呼机会（不是按批刷新而是按天刷新）。注意，不可省略前半句“我想收**一些**妹妹”，防止预期错位。
4. （每批5分钟，每天2批，每周4天）小红书盯着私信列表，对于应了招呼的女生：不断把她的注意力拉回到确定兄妹关系这件事上。
5. （每批5分钟，每天8批，每周4天）微信小红书盯着私信列表，对于说过愿意、回了消息、守着纪律的女生：双方对等进行情绪上的义务劳动（起床早安、睡觉晚安，多叫妹妹、多说喜欢，有想说的提问回答、没想说的语气词表情包，分享有意思的日常、分享有意思的作品）。注意：情绪劳动必须**对等**，不可为了数量牺牲质量。尽量在小红书聊，如果对方要求加微信那就加，加完问清楚之后用小红书聊还是用微信聊。特殊日子可以寄手写贺卡，除此之外禁止赠送任何物品，包括虚拟物品，也禁止转账。对于破坏纪律的女生：初犯重新对齐预期，再犯减少心智投入，三犯直接删除拉黑。切记：永远不要争论。

## 纪律

1. 遵守法律、遵守平台规定。
2. 哥哥无条件爱妹妹、妹妹无条件偏袒哥哥。
3. 允许随时中断对话、允许一段时间不联系。
