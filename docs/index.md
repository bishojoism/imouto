# 处兄妹攻略

## 大致情况（保守估计只多不少）

1. 热门作品评论要哥哥的每4周固定160个
2. 响应招呼愿意当妹妹的每4周大约32个
3. 顶多两次就能联系上的每4周大约4个
4. 相处期间始终守边界的每4周大约1个

## 具体步骤（四十分钟上四休三）

1. （只需1次）准备微信，昵称头像简介填低龄化的，性别年龄地区填真的，可白板号可老号，但最好将朋友圈设为三个月可见。
2. （只需1次）准备小红书，昵称头像简介填低龄化的，性别年龄地区填真的，可白板号可老号，但最好将你关注了谁、谁关注了你设为仅自己可见。
3. （每批5分钟，每天2批，每周4天）小红书搜“收妹妹处兄妹”作品，对于评论区里新留言要哥哥的：关注并私信“我想收一些妹妹，你能当我妹妹吗”，直到用完小红书每天的10次招呼机会（不是按批刷新而是按天刷新）。注意，不可省略前半句“我想收**一些**妹妹”，防止预期错位。
4. （每批5分钟，每天2批，每周4天）小红书盯着私信列表，对于应了招呼的：不断把她的注意力拉回到确定兄妹关系这件事上。
5. （每批5分钟，每天4批，每周4天）微信小红书盯着私信列表，对于说过愿意、回了消息、守着边界的：双方对等进行情绪上的义务劳动（起床早安、睡觉晚安，多叫妹妹、多说喜欢，有想说的提问回答、没想说的语气词表情包，分享有意思的日常、分享有意思的作品）。注意，情绪劳动必须**对等**，不可为了数量牺牲质量。尽量在小红书聊，如果对方要求加微信那就加，加完问清楚之后用小红书聊还是用微信聊。特殊日子可以寄手写贺卡，除此之外禁止赠送任何物品，包括虚拟物品，也禁止转账。对于无意逾越边界的：重新对齐预期。对于蓄意破坏边界的：直接删除拉黑。

## 边界设置（自觉加上相互提醒）

1. 遵守法律、遵守平台规定。
2. 哥哥无条件爱妹妹、妹妹无条件偏袒哥哥。
3. 允许随时中断对话、允许一段时间不联系。
