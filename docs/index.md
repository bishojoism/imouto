# 网聊

## 4.0

### 四项原则

1. 隐形冠军筛选原则：竞争小需求大 身段低素质高
2. 氧气面罩相处原则：首先照顾自己 其次回应对方
3. 跷跷板对话原则：你主导一会儿 她主导一会儿
4. 外交官沟通原则：既要守住底线 又要护住场面

### 四项工艺

- 私信截流筛选工艺：搜`找女朋友`作品 翻`找男朋友`评论 表白`真省事儿的女生` 限定`有边界感的那种`
- 身体锚定相处工艺：来消息后关注呼吸的起伏 回消息前关注地面的支撑 动不动喝水上厕所 时不时活动伸懒腰
- 提升关系：“早安/晚上好” “宝宝/亲爱的” “贴贴/特别喜欢” “谢谢/特别感激”
- 修复关系：“你的这个要求/这个做法” “让我很不舒服/很有压力” “实在不能答应/忍不了” “真的不好意思/对不住”
