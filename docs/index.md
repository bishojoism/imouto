2. **氧气面罩**：按照“首先照顾自己，其次回应对方”的顺序。来消息察呼吸起伏、回消息觉地面支撑，动不动喝水上厕所、时不时活动伸懒腰。舒服了再聊天、难受就歇会儿，宁跟对方为此事闹掰、不让自己受这种委屈。
3. **跷跷板**：在平常对话中“你主导一会儿，她主导一会儿”。语气词不敷衍、表情包不冷漠，提问时让对方有的回答、回答时让对方有的提问。不喊宝宝也不说早安、不喊想念也不说喜欢，可送手写贺卡、禁送其他礼物。
4. **外交官**：当发生矛盾时“既能守住底线，又能护住场面”。你这样让我很有压力、你这样让我很不舒服，我实在无法理解、我实在答应不了。不摆事实也不讲道理、不摆利益也不讲对错，无视她的攻击、重复你的台词。
